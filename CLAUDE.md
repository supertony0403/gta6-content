# GTA-6-Content (Clipping-Werkstatt)

Arbeitsordner fuer das Plugin `gta6-skill` (installiert, user scope). Alle Skills mit Praefix aufrufen,
z. B. `/gta6-skill:kampagnen-finder`. Ablauf und Regeln: siehe README.md.

- Nur Material clippen, das eine Kampagne oder der Rechteinhaber ausdruecklich erlaubt.
- Nichts posten oder einreichen ohne Ja von Anthony; Posten macht Anthony selbst.
- Quellmaterial, MP4s und tracker.csv sind per .gitignore aus dem Repo ausgeschlossen.
- Werkzeuge: yt-dlp (pip --user, Konfig ~/.config/yt-dlp/config mit --js-runtimes node), ffmpeg 9, faster-whisper (Python-Modul).
